# 📚 Apni Vidya - Learning Management System

A comprehensive, modern Learning Management System (LMS) built with TypeScript for managing courses, students, and educational content.

## ✨ Features

- **Course Management** - Create, update, and manage courses
- **Student Enrollment** - Easy enrollment and tracking system
- **Interactive Learning** - Engaging course materials and lessons
- **Progress Tracking** - Monitor student progress and achievements
- **Responsive Interface** - Optimized for all devices
- **User Roles** - Separate dashboards for students, instructors, and admins

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Next.js, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Deployment**: Vercel

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Mr-Saransh/apnividya_main.git
cd apnividya_main

# Install dependencies
npm install

# Configure environment
cp .env.example .env.local

# Start development server
npm run dev
```

Access the live application at [https://apnividya-main-frontend.vercel.app](https://apnividya-main-frontend.vercel.app)

## 📊 Key Modules

- **Courses Module** - Full course lifecycle management
- **Student Management** - Enrollment and progress tracking
